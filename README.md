# 🌍 Sri Traveler

Sri Traveler is a full-stack **tourism and travel management platform** designed to connect **travelers (users)** with **tour guides (guiders)** in Sri Lanka. The system enables users to discover trips, book travel packages, hire guides, and communicate in real-time after booking confirmation.

It includes a **mobile application for users (Flutter)** and a **web platform for guiders**, creating a complete ecosystem for modern travel experiences.

## 📌 Project Overview

Sri Traveler acts as a **bridge between travelers and guides**:

### 👤 Users (Travelers)
- Browse travel destinations and packages
- Save favorite trips
- Book travel packages
- Hire professional guiders
- Chat with guiders after confirmation

### 🧭 Guiders (Tour Guides)
- Register and manage profile
- Create and manage travel packages
- Save trips and offerings
- Accept or reject user bookings
- Chat with users after acceptance

## 📱 System Architecture

The platform is divided into two main systems:

### 1️⃣ Mobile Application (Flutter)
- User-side application

### 3. Trip & Package Module

### 4. Booking Module
Handles booking lifecycle:
- Request → Accept/Reject → Confirmed → Chat enabled

### 5. Chat Module
Enables secure communication between user and guider.

---

## 🔄 System Workflow

1. User registers and logs in
2. User browses available trips and guiders
3. User books a trip or hires a guider
4. Guider receives booking request
5. Guider accepts or rejects request
6. If accepted:
   - Booking is confirmed
   - Chat system becomes active
7. User and guider communicate for trip planning
